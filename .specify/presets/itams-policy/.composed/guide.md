## Clouds post-implementation living-spec overlay

This overlay intentionally changes upstream Spec Kit v1.0.13 living-spec mutation timing while retaining its schemas and artifact roles. New or convention-free Clouds projects default to this overlay. An existing project with a different established persistence convention requires designated-owner approval before migration; this repository's migration is already expressly approved.
