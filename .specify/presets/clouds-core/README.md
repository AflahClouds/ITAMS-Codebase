# Clouds Core preset

This preset layers a business-facing guide and a small set of governance addenda over the commands bundled with GitHub Spec Kit v1.0.13. It deliberately leaves the upstream spec, plan, research, task, checklist, and code artifact formats intact.

Install for local development from an initialized Codex Spec Kit project:

```powershell
specify preset add --dev <path-to-clouds-core> --priority 5
```

The new Codex skill is `$speckit-guide`. Existing skills remain `$speckit-*`.
